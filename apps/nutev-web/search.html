Construtor de estratégia

O NutEV compila uma query por base. Ele não inventa vocabulário controlado: MeSH/DeCS precisam estar explicitamente aprovados nesta estratégia.

Um termo por linha. Use mesh:Termo, decs:Termo ou free:termo livre. Sem prefixo = texto livre. Sinônimos ficam no mesmo bloco e são unidos por OR; blocos diferentes são unidos por AND.
Estratégia eletrônica exata

Use este modo para estratégias já versionadas/revisadas. O NutEV preserva literalmente operadores, campos, headings, filtros e datas; não converte nem simplifica a string.

Selecione abaixo apenas as bases que possuem uma string aprovada. Para cada base selecionada, cole a consulta exatamente como deve ser enviada. Em modo exato, “Busca global” remove o teto apenas dessas bases; não adiciona providers sem query.
A estratégia só será usada quando este modo estiver ativado.
Fontes e limites
carregando fontes…
Busca global = sem teto interno. Não há corte interno de 100, 300 ou outro número. No modo comum, usa todas as fontes conectadas. No modo de estratégia exata, usa somente as bases para as quais existe query exata e que estão selecionadas. Limites ou bloqueios impostos pela própria fonte permanecem explícitos.
