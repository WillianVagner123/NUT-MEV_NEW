Organize os conceitos principais. Se você já validou MeSH ou DeCS, pode incluí-los; caso contrário, use termos livres.

Como preencher os termos
Um termo por linha. Use mesh:Termo, decs:Termo ou free:termo livre. Termos no mesmo bloco são alternativas; blocos diferentes são combinados entre si.
