Registry semantics

O registry é autoridade sobre o estado de governance, não sobre a verdade científica.

STAGED

Artefato recebido e revalidado. Nenhuma aprovação humana registrada.

APPROVED_FOR_GOVERNED_USE

Governance humana aprovou uso controlado do artefato. Não equivale a certainty ou scientific validation.

REJECTED_BY_GOVERNANCE

Governance humana rejeitou o uso controlado. Não equivale a exclusão PRISMA do estudo fonte.

Scientific boundary

Import != approval · approval != evidence certainty · governance identity field != cryptographic identity authentication · registry record != accepted EvidenceClaim · governed use != meta-analysis · registry != PRISMA · approved entries may feed a governed release, but that release still does not create canonical scientific synthesis.
