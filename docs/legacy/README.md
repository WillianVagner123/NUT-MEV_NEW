# Legacy research-workflow documentation

These documents describe historical research workflows and are not part of the NutEV Reference Engine v1.0.0 runtime or supported product workflow.

The supported v1 product is limited to:

```text
SEARCH -> NORMALIZE -> DEDUPLICATE -> RANK -> EXPORT
```

Historical material may refer to systematic/scoping-review orchestration, PRISMA, PRESS, FREEZE, GF scientific gates, human screening, manuscript readiness or the former NutEV Evidence Engine identity. Those concepts are preserved only for provenance, compatibility and research-history traceability.

Do not use legacy documents as the Quick Start or release specification for v1.0.0.

The current release boundary and inventory are documented in `../RELEASE_V1_AUDIT.md`.
